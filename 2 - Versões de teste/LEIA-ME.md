# Versões de teste

Builds para você validar antes de virarem oficiais. O nome diz qual versão ele
prepara e qual tentativa é:

```text
New Gods Unlimited V1.1.0-teste.1.exe   primeiro teste da futura V1.1.0
New Gods Unlimited V1.1.0-teste.2.exe   segundo teste, com ajustes do primeiro
```

Quando um teste é aprovado, ele é publicado como oficial (`V1.1.0`) em
`1 - Versão oficial/`, e os testes daquela versão vão para `_histórico/`.

## `_histórico/`

Entregas antigas, só para consulta. Cada pasta começa com a data:

- `2026-10-16 …` e `2026-10-17 …` — builds da época em que o programa se chamava "Ecossistema Neural";
- `2026-10-24 visao-pf-experimental` — a primeira build experimental de visão + PF, substituída pela `V1.1.0-teste.1`.
