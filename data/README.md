# Dados locais

Esta pasta separa os dados produzidos durante o uso do projeto do código e da
documentação versionados.

- `runs/`: sessões salvas (`.ecosrun`);
- `campaigns/`: campanhas do laboratório (`.ecos`);
- `presets/`: presets criados durante uma sessão.

Esses arquivos são pessoais ou resultados de experimentos e ficam fora do Git
por padrão. Para transformar um deles em referência do projeto, mova uma cópia
revisada para `assets/presets/` e faça um commit.
