# Arquivo histórico

Materiais preservados apenas para consulta ficam aqui. Em especial,
`archive/releases/` guarda as cópias portáteis anteriores à reorganização de
17 de outubro de 2026. Elas não entram no Git, pois são binários gerados e
podem ocupar espaço desnecessário no histórico.

A entrega ativa fica em `releases/windows/current/`. Quando uma versão nova
substituir a atual, mova a cópia anterior para este diretório antes de publicar
a próxima.
